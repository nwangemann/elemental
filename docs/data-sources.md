# Data sources

None are used yet. Planned for milestone 1, fetched at build time and committed as JSON:

| Source                                                                           | Licence                    | Used for                                                                                                                                            |
| -------------------------------------------------------------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| [PubChem periodic table](https://pubchem.ncbi.nlm.nih.gov/periodic-table/) (NIH) | US government work, public | Atomic weight, configuration, electronegativity, radius, ionization energy, state, melting and boiling points, density, group block, discovery year |
| [Wikidata](https://www.wikidata.org/)                                            | CC0                        | Discoverers, etymology, isotopes, links                                                                                                             |

Reference values are checked against [IUPAC](https://iupac.org/) and [NIST](https://www.nist.gov/pml/atomic-spectra-database).
