elemental is a walkable 3D periodic table for the browser: a small figure walks across the tiles, each element reacts when stepped on, and a panel shows its data. Built with Vite, React 19, TypeScript 7 and, from milestone 1, three.js through React Three Fiber.

## Library APIs

three.js, React Three Fiber and drei change quickly. Do not code from memory: read the installed package's types in `node_modules` first, then the docs for the installed version.

## Rules

- Use npm. Node 24+.
- `src/core` is pure TypeScript: no React, three or DOM imports. Put maths, layout and data shaping there and unit-test it.
- Per-frame code lives in `useFrame`, mutates refs and reused objects, and never calls `setState`.
- Element data is generated by a script and committed; the app makes no runtime API calls.
- Every data source goes in `docs/data-sources.md`, every dependency in `docs/dependencies.md`, every bundled asset in `THIRD_PARTY_NOTICES.md`.
